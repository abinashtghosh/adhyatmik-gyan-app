# Adhyatmik Gyan – Puja, Vastu & Dharmik Upay

Free starter PWA for the Adhyatmik Gyan devotional channel.

## Current version
- Hindi-first interface with an English language button placeholder
- Daily Dharmik Message
- Today's Puja / Vrat
- Puja categories: Ganesh, Lakshmi, Shiv, Hanuman, Krishna, Durga, Vishnu, Tulsi
- Vastu Tips, Mantra and Festival Calendar sections
- Latest YouTube channel button
- **Free Kundali Consultation only**: the form opens an email draft to `buzzjamshedpur@gmail.com`; detailed analysis is manually prepared and emailed by the admin
- No paid consultation or payment feature
- PWA manifest and service worker
- Saffron + gold devotional design

## GitHub Pages
1. Upload all files/folders to the repository root.
2. Repository → Settings → Pages.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then Save.
5. GitHub will provide the live site URL.

## Important privacy note
Do not put passwords, API keys, private email credentials, or customer data into this public repository. The current Kundali form uses the visitor's email client; it does not store submitted details in GitHub.
